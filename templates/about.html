About the Project

The Employee Management System is a web-based application developed using Flask and MySQL. It helps administrators manage employee information efficiently. The system provides secure user authentication and allows administrators to perform employee management operations through a simple and responsive interface.

This project includes user registration, login, dashboard, employee management, password recovery through email, and contact functionality.

Project Features

  • ✔ User Registration
  • ✔ Secure Login System
  • ✔ Dashboard
  • ✔ Add Employee
  • ✔ View Employee Details
  • ✔ Edit Employee Details
  • ✔ Delete Employee
  • ✔ Forgot Password
  • ✔ Reset Password using Email
  • ✔ Contact Form
  • ✔ Responsive Design
